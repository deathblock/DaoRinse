DaoRinse is a cloud-based platform utilizing real-time data processing and auto-scaling capabilities to optimize service delivery.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoRinse.git`
2. `cd DaoRinse`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
